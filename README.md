# BasePicks AI ⚾🤖
**Advanced MLB Sabermetrics & AI Handicapping Platform**

BasePicks AI is a premium sports analytics web application designed to give sports bettors a mathematical edge (+EV) over Vegas sportsbooks. By combining real-time MLB data, advanced sabermetrics, and a custom-tuned LLM (Buddy AI), the platform identifies value bets and provides interactive, context-aware betting analysis.

## 🚀 Live Project
**Website:** [basepicksai.com](https://basepicksai.com)

## 🧠 Core Features
* **Buddy AI Chat:** A highly specialized AI assistant (powered by Google Gemini) that analyzes matchups, pitcher stats, and odds to find positive expected value (+EV).
* **Live Match Center:** Real-time MLB box scores, linescores, and game status tracking.
* **Admin Control Room:** Secure dashboard for manual odds input and official VIP forecast publishing.
* **Crypto Paywall:** Fully automated VIP subscription management system via Plisio (USDT/TON).
* **Viral Referral Engine:** Built-in affiliate system rewarding users with free VIP days for bringing in new paying customers.
* **PWA Ready:** Installable as a native-like app on iOS and Android.

## 🛠️ Tech Stack
* **Frontend:** Vanilla HTML5, CSS3, JavaScript (Zero framework dependency for max performance).
* **Backend:** Python, FastAPI (High-performance asynchronous API).
* **Database & Auth:** Supabase (PostgreSQL, Row Level Security, OAuth).
* **AI Engine:** Google Gemini 2.5 Flash API.
* **Payments:** Plisio Crypto Gateway.
* **Hosting:** Vercel (Frontend) & Render (Backend).
